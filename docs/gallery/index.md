# Gallery

Each example below is a live Umwelt viewer: a visualization, a structured textual description, and a sonification, all generated from the same specification. Every example links into the [editor](https://umwelt-data.github.io/umwelt/editor/), where you can remix it — swap fields, change encodings, or load your own data.

New to Umwelt? Start with the [getting started guide](/using/) for a tour of the editor. Want to embed a viewer in your own site? See the [developer quickstart](/docs/quickstart).
